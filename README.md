## About the project

I wanted to combine this assignment with something I am interested in, so I made a portfolio about my games. It shows what I have already made and what I can bring to a project as a developer.

## Task 0 - Navigation bar

I used Flexbox for the header. The logo is on the left, and the Home, Projects, and Gallery links are on the right. These links take you to sections of the page. I used `justify-content: space-between` to separate the logo and the links, `align-items: center` to line them up, and `gap` for the space between links.

I also added links to my GitHub and itch.io profiles in the sidebar. I usually upload my games there.

## Task 1 - Card row

The three cards show my games: Criminally Delicious, Deep Dive, and Larping Skeleton. I placed the cards in a row with Flexbox. They have the same height, and the buttons stay at the bottom of each card. A shadow appears when you hover over a card.

## Task 2 - Page layout with grid areas

In the final page, I used Grid for the main layout and for the projects and info section. I used Flexbox for the navigation and the project cards.
